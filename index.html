How to use this

This is a screening aid built from FDA recall/enforcement information. Machine-imported records are shown only when they match a brand already represented in the CatFood Compass nutrition catalog. A missing match is not proof that a product has never been recalled. For an affected product, compare the exact lot/UPC/package details with the FDA notice before acting.

The brand whitelist prevents unrelated products that merely contain words like “cat” from entering the recall list. The bundled file works offline. A scheduled GitHub Action can refresh it automatically, and “Check openFDA now” performs the same catalog-brand screening for a session-only live query.

Know what the numbers mean

About the data

What this app displays

The app starts in a neutral Normal profile. Specialized profiles change which available nutrients are emphasized and can apply user-configured shopping targets without changing the underlying source record.

The seed chart reports protein, fat, and carbohydrate as percent of calories, phosphorus as mg per 100 kcal, and calories per the package size noted by the source.

That is different from the as-fed Guaranteed Analysis printed on most cans.

Multiple source generations

The original 2017 Pierson chart remains available as a historical reference. Newer FDSG wet-food rows include source dates when present, and the FDSG dry list is intentionally carb-focused rather than pretending missing macros or minerals are known.

Profiles are screening lenses

Normal is intentionally condition-neutral. Diabetes emphasizes carbohydrate; Kidney and Urinary can emphasize minerals; Weight emphasizes calorie density; Oncology and Custom/Vet are configurable. Targets indicate whether a record fits the selected numbers, not whether a food is medically appropriate.

Blank and unusual values stay visible

If a source did not provide a value, this app keeps it missing rather than substituting zero. Source arithmetic anomalies are flagged and preserved rather than silently “fixed.”

Historical names stay historical

Source product names are never overwritten by modern shelf names. Verified current-name mappings live in a separate alias layer, so a search can find a modern package without changing the historical record.

Included sources

Cat Food – Nutritional Composition (Lisa A. Pierson, DVM, 2017), plus the supplied Known values for Cat Foods – Wet and Dry Food List – Compiled for FDSG.

Tiki Cat reconciliation layer: a separate current-catalog database links verified Tiki shelf names to historical/FDSG observations without replacing any original nutrition values.

FPUO: the supplied FDSG wet compilation is marked “For personal use only.” Those records remain in this single app and are visibly tagged FPUO so their provenance is never hidden.

FDA recall layer: a separate bundled recall/advisory snapshot is refreshed independently of the nutrition records. Machine records must match the app’s catalog-brand whitelist, and recall matching never rewrites nutrition data.

This app is a shopping and record-keeping aid. Nutrient targets and treatment decisions for a cat with diabetes or other disease should stay aligned with the cat's veterinary plan.

Settings

Normal is the default neutral profile. Specialized profiles change which nutrients are emphasized. Numeric targets are shopping filters only; they are not a diagnosis, treatment plan, or claim that a food is medically “safe.”

Normal

No automatic nutrient limits. All source values remain available for browsing, sorting, and manual filters.

Diabetes screening

Carbohydrate is emphasized. The source-derived starting target is ≤10% of metabolizable calories.

Kidney screening

No universal cutoff is assumed. Set the limits supplied for your cat's plan.

Urinary screening

Use only the mineral limits that are relevant to the veterinary plan; missing source values stay missing.

Weight-management screening

Calorie density is emphasized when kcal/100 g is available. Package-only calorie values are still shown but are not treated as equivalent density data.

Cancer / oncology

There is no universal cancer-food preset. This profile is intentionally configurable so targets can follow the individual diagnosis, treatment, appetite, and veterinary plan.

Custom / Vet profile

Build a target set around whichever nutrients matter for your cat.
